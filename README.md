# projetoYoga — LIFE

App para celular e site web.

## Estrutura

- `docs/` — documentação do projeto
  - `Documento_Mestre_Motor_LIFE_1.0.docx` — documento mestre
  - `LIFE_Matriz_Tecnica_1.1.xlsx` — matriz técnica
  - `storytelling.txt` — storytelling
  - `midias de flow/` — referências visuais dos flows

## Fluxo de trabalho (celular ↔ computador)

- **No computador:** `git pull` antes de começar, `git push` ao terminar.
- **No celular:** abrir [claude.ai/code](https://claude.ai/code) e selecionar este repositório.
